蜂窝数据设置

注意：开启会产生蜂窝流量；部分漫游 SIM、模组与运营商组合在激活数据 PDP 后可能影响短信承载。本机经 WiFi 转发时通常无需开启，建议保持关闭。

默认关闭=禁用 PDP，零流量。仅在需要保号 HTTP payload / 蜂窝 IP 时临时开启。

同手机“数据漫游”：关闭后设备处于漫游网络(CEREG=5)时不激活蜂窝数据、不跑漫游流量。该开关仅控制数据 PDP，不直接判断短信可用性；漫游短信是否可用由 SIM、模组与运营商网络共同决定。

从列表选运营商或手动填 PLMN(MCC+MNC，国外同理)。仅能选 SIM 可接入的网络，锁定不可达会失网；不确定留空自动。

多数 eSIM/数据卡不通过 CNUM 上报本机号码，模组读不到时概览会显示这里的手填值。换卡后请更新或清空，否则会一直显示旧号码。
